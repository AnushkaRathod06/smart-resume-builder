SMART RESUME BUILDER
====================

1. Install Python 3.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   pip install -r requirements.txt
5. Run:
   python app.py
6. Open the address shown in the terminal, usually:
   http://127.0.0.1:5000

FEATURES
- Home page
- Resume builder form
- Personal details
- Career objective
- Education
- Skills
- Projects
- Experience
- Certifications
- Languages
- Resume preview
- Print / Save as PDF
- Responsive design
